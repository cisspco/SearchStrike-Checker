## 캐페인 개요
변동 없음 — 전날과 동일. SearchStrike는 KISA가 명명한 헌팅 가이드이며, 공개 위협 인텔리전스 업계에서는 동일 캠페인이 **EtherRAT**로 광범위하게 추적됨. GitHub에 Tftpd64·Postman·WinDbg·PsExec·USMT·IntuneWinAppUtil·BgInfo·RDCMan 등 정상 관리 도구를 가장한 트로이목마화 MSI 설치파일을 올리고 SEO로 검색 상위 노출시켜 유포. 실행 시 %LOCALAPPDATA%\<랜덤 6자>\에 node.exe를 심고 Run 키/hex 서브키로 지속성을 확보하며, msiexec→cmd→node.exe 또는 explorer→node.exe 프로세스 체인으로 재실행됨. C2는 이더리움 스마트 컨트랙트에 저장된 주소를 공개 RPC 엔드포인트로 조회해 얻는 "EtherHiding" 방식.

이번 실행에서 WebSearch로 새로 발견된 관련 보도(cybersecuritynews.com의 "Hackers Use EtherRAT and EtherHiding", sysdig.com의 "React2Shell attacks" 분석, atos.net의 "GitHub Facades" 분석 등)는 모두 EtherRAT/SearchStrike의 기존에 알려진 특징(SEO 포이즈닝, GitHub 사칭 저장소, 이더리움 RPC를 통한 C2 조회)을 재확인할 뿐, 신규 C2 도메인·해시·RPC 엔드포인트를 스니펫에 노출하지 않았고 해당 사이트는 모두 페치가 차단되어 본문을 확인하지 못함. GitHub PJO2/tftpd64 이슈 #46은 이전 실행에서 이미 검토된 것과 동일한 해시 6건을 다시 보여줄 뿐이며, SearchStrike와의 연관성은 여전히 확인되지 않아 이번에도 채택하지 않음.

## 호스트 IOC · 행위
- %LOCALAPPDATA%\<랜덤 6자 알파뉴메릭>\...\node.exe — 악성 node.exe 드롭 경로
- HKCU/HKLM \Software\Microsoft\Windows\CurrentVersion\Run — node.exe 실행 항목 지속성
- HKCU\Software\<hex 랜덤 서브키> — 값이 .cfg/.ini/.bin/.bak 또는 LOCALAPPDATA 경로인 경우 의심
- 프로세스 체인: msiexec.exe → cmd.exe → node.exe (초기 감염), explorer.exe → node.exe (재부팅 후 Run 키 실행)
- %LOCALAPPDATA%, %APPDATA%, %TEMP% 내 고엔트로피(Shannon ≥7.2) .xml/.bak/.cfg/.bin/.ini 페이로드
- %LOCALAPPDATA%\Temp 내 랜덤명(4~16자 영숫자) .cmd 스크립트 — MSI 설치 잔존물
- node.exe가 conhost.exe를 경유해 문서화되지 않은 `--headless` 인자로 실행됨 — ⚠️ (미검증, 원문 미페치)
- 지속성 확보 후 AD 도메인 소속·시스템 로캘 등을 정찰하고 추가 Node.js 런타임을 내려받아 이더리움 RPC 엔드포인트·지갑 주소를 대상으로 함 — ⚠️ (미검증, 원문 미확인, 기존 캠페인 형태와 일치)
