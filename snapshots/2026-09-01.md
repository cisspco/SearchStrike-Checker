## 캠페인 개요
변동 없음 — 전날과 동일. SearchStrike는 KISA/THORCERT가 명명한 헌팅 가이드이며(원문: thorcert.notion.site "Operation SearchStrike-IT", 이번 실행에서 페치 차단), 공개 위협 인텔리전스 업계에서는 동일 캠페인이 **EtherRAT**로 광범위하게 추적됨(이번 실행의 다건 WebSearch 스니펫으로 재확인, 원문 다수 차단으로 여전히 미검증). GitHub에 Tftpd64·Postman·WinDbg·PsExec·USMT·IntuneWinAppUtil·BgInfo·RDCMan 등 정상 관리 도구를 가장한 트로이목마화 MSI 설치파일을 올리고 SEO로 검색 상위 노출시켜 유포. 실행 시 %LOCALAPPDATA%\<랜덤 6자>\에 node.exe를 심고 Run 키/hex 서브키로 지속성을 확보하며, msiexec→cmd→node.exe 또는 explorer→node.exe 프로세스 체인으로 재실행됨. C2는 이더리움 스마트 컨트랙트에 저장된 주소를 공개 RPC 엔드포인트로 조회해 얻는 "EtherHiding" 방식. 신규(이번 실행, WebSearch 스니펫 기준, ⚠️ 미검증): sk-shieldus.com 관련 스니펫에 따르면 지속성 실행 시 node.exe가 conhost.exe를 경유하며 문서화되지 않은 `--headless` 인자를 사용한다는 언급이 있음 — 원문 미확인. Malwarebytes(2026-06)가 EtherRAT 배포 인프라(피싱 페이지 포함)를 다룬 리포트를 게시했다는 검색 결과 확인되었으나 페치 차단으로 세부 IOC 미확인.

## 호스트 IOC · 행위
- %LOCALAPPDATA%\<랜덤 6자 알파뉴메릭>\...\node.exe — 악성 node.exe 드롭 경로
- HKCU/HKLM \Software\Microsoft\Windows\CurrentVersion\Run — node.exe 실행 항목 지속성
- HKCU\Software\<hex 랜덤 서브키> — 값이 .cfg/.ini/.bin/.bak 또는 LOCALAPPDATA 경로인 경우 의심
- 프로세스 체인: msiexec.exe → cmd.exe → node.exe (초기 감염), explorer.exe → node.exe (재부팅 후 Run 키 실행)
- %LOCALAPPDATA%, %APPDATA%, %TEMP% 내 고엔트로피(Shannon ≥7.2) .xml/.bak/.cfg/.bin/.ini 페이로드
- %LOCALAPPDATA%\Temp 내 랜덤명(4~16자 영숫자) .cmd 스크립트 — MSI 설치 잔존물
- node.exe가 conhost.exe를 경유해 문서화되지 않은 `--headless` 인자로 실행됨 — ⚠️ (미검증, WebSearch 스니펫만 확인, 원문 미페치)
