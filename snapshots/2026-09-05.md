## 캠페인 개요
변동 없음 — 전날과 동일. SearchStrike는 KISA/THORCERT가 명명한 헌팅 가이드이며, 공개 위협 인텔리전스 업계에서는 동일 캠페인이 **EtherRAT**로 광범위하게 추적됨. GitHub에 Tftpd64·Postman·WinDbg·PsExec·USMT·IntuneWinAppUtil·BgInfo·RDCMan 등 정상 관리 도구를 가장한 트로이목마화 MSI 설치파일을 올리고 SEO로 검색 상위 노출시켜 유포. 실행 시 %LOCALAPPDATA%\<랜덤 6자>\에 node.exe를 심고 Run 키/hex 서브키로 지속성을 확보하며, msiexec→cmd→node.exe 또는 explorer→node.exe 프로세스 체인으로 재실행됨. C2는 이더리움 스마트 컨트랙트에 저장된 주소를 공개 RPC 엔드포인트로 조회해 얻는 "EtherHiding" 방식.

이번 실행 검색에서 새로 나타난 관련 보도(cybersecuritynews.com·infosecurity-magazine.com·cointrust.com — 기존에 확인된 트로이목마화 Tftpd64 EtherRAT 변종 기사의 재게재/재요약으로 보임, gbhackers.com — 이더리움 스마트컨트랙트 C2 일반 기사)는 모두 검색 스니펫 수준에서만 확인되었고 원문 페치는 프록시 차단으로 실패. eSentire 관련 스니펫에서 "EtherRAT이 1rpc[.]io라는 공개 이더리움 RPC 서비스를 조회해 스마트 컨트랙트를 읽는다"는 신규 언급을 확인 — eSentire 원문 자체는 이전 실행부터 계속 차단 상태라 미검증으로 분류, RPC 후보 목록에 추가함. endorlabs.com·cryptika.com 기사에서 언급된 "Dark Caracal / GoCaracal"은 별도 악성코드·행위자로 소개되어 SearchStrike/EtherRAT와 동일 캠페인으로 확인되지 않아 IOC로 채택하지 않음(맥락 정보로만 취급).

## 호스트 IOC · 행위
- %LOCALAPPDATA%\<랜덤 6자 알파뉴메릭>\...\node.exe — 악성 node.exe 드롭 경로
- HKCU/HKLM \Software\Microsoft\Windows\CurrentVersion\Run — node.exe 실행 항목 지속성
- HKCU\Software\<hex 랜덤 서브키> — 값이 .cfg/.ini/.bin/.bak 또는 LOCALAPPDATA 경로인 경우 의심
- 프로세스 체인: msiexec.exe → cmd.exe → node.exe (초기 감염), explorer.exe → node.exe (재부팅 후 Run 키 실행)
- %LOCALAPPDATA%, %APPDATA%, %TEMP% 내 고엔트로피(Shannon ≥7.2) .xml/.bak/.cfg/.bin/.ini 페이로드
- %LOCALAPPDATA%\Temp 내 랜덤명(4~16자 영숫자) .cmd 스크립트 — MSI 설치 잔존물
- node.exe가 conhost.exe를 경유해 문서화되지 않은 `--headless` 인자로 실행됨 — ⚠️ (미검증, 원문 미페치)
- 지속성 확보 후 AD 도메인 소속·시스템 로캘 등을 정찰하고 추가 Node.js 런타임을 내려받아 이더리움 RPC 엔드포인트·지갑 주소를 대상으로 함 — ⚠️ (미검증, 원문 미확인, 기존 캠페인 형태와 일치)
